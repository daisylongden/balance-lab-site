# Balance Lab website

Static site for [balance-lab.nl](https://balance-lab.nl), hosted on GitHub Pages from the `main` branch.

- `index.html`: landing page
- `how-we-use-ai/`: how we use AI (red lines and commitments)
- `who-we-work-with/`: the areas we work in
- `assets/`: favicon and photos
- `CNAME`: the custom domain

Brand source of truth: the Balance Lab brand kit in Figma.
