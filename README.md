# Balance Lab website

Static site for [balance-lab.nl](https://balance-lab.nl), hosted on GitHub Pages from the `main` branch.

- `index.html`: landing page
- `how-we-use-ai/`: how we use AI (red lines and commitments)
- `who-we-work-with/`: the areas we work in
- `assets/`: favicon and photos
- `CNAME`: the custom domain

Brand source of truth: the Balance Lab brand kit in Figma.

## Visitor tracking

The site uses [Cloudflare Web Analytics](https://www.cloudflare.com/web-analytics/) (free). It sets no cookies and stores no personal data, so no cookie banner is needed. The snippet sits just before `</body>` on every page. Any new page needs the same snippet. Stats are in the Cloudflare dashboard under Analytics & Logs, then Web Analytics.
